# Project Rules & Instructions

## Automatic Git Commit & Sync
For any changes requested by the user from here on out:
1. **Stage**: Stage all modified, created, or deleted files relevant to the requested task (`git add <files>`).
2. **Commit**: Create a commit with a concise, descriptive commit message explaining the change (`git commit -m "<message>"`).
3. **Sync / Push**: Push the commit to the active remote branch (`git push`) to keep the remote synchronized. If a network sandbox prompt is required, request user approval to push.
